# 🔊 Гайд по звукам для botyaraclick

## Где искать

**Freesound.org** — https://freesound.org/
Бесплатная библиотека звуков. Ищи звуки с лицензией:
- **Creative Commons 0 (CC0)** — полностью бесплатно, без ограничений
- **Creative Commons Attribution (CC BY)** — бесплатно, нужно указать автора

## Куда класть

```
botyaraclick/assets/sounds/    ← звуковые эффекты (SFX)
botyaraclick/assets/music/     ← фоновая музыка
```

## Формат файлов

- **Звуки (SFX):** `.wav` или `.ogg` (pygame лучше работает с .wav для коротких звуков)
- **Музыка:** `.ogg` (меньший размер для длинных треков)

## 📋 Список необходимых звуков

### 🖱️ Клик (самый важный!)
- **Файл:** `assets/sounds/click.wav`
- **Длительность:** 0.05–0.15 секунд (очень короткий!)
- **Поиск на Freesound:** `mouse click`, `button click`, `ui click`, `tap`
- **Какой должен быть:** Мягкий, приятный щелчок. НЕ громкий, НЕ резкий — 
  игрок будет слышать его тысячи раз! Лучше что-то "мягко-механическое".
- **Рекомендуемые запросы:**
  - `soft click` — мягкий клик
  - `mouse button` — звук кнопки мыши
  - `keyboard key` — нажатие клавиши
  - `pop` — мягкий поп-звук

### 💰 Клик (критический)
- **Файл:** `assets/sounds/click_crit.wav`
- **Длительность:** 0.1–0.3 секунд
- **Поиск:** `coin drop`, `cash register ding`, `power up short`
- **Какой должен быть:** Более яркий и заметный, чем обычный клик. 
  Звон монетки или короткий "пинг" удовлетворения.

### 🛒 Покупка
- **Файл:** `assets/sounds/buy.wav`
- **Длительность:** 0.2–0.5 секунд
- **Поиск:** `purchase`, `cash register`, `coin`, `buy sound`, `cha-ching`
- **Какой должен быть:** Звук кассы, звон монет, или приятный "ча-чинг".

### 🚫 Ошибка (нет денег)
- **Файл:** `assets/sounds/error.wav`
- **Длительность:** 0.2–0.4 секунд
- **Поиск:** `error buzz`, `wrong answer`, `negative beep`, `denied`
- **Какой должен быть:** Короткий негативный звук, но не раздражающий.

### 🏆 Достижение

- **Длительность:** 0.5–1.5 секунд
- **Поиск:** `achievement unlocked`, `level up`, `fanfare short`, 
  `success jingle`, `trophy`
- **Какой должен быть:** Победная мелодия, фанфара, или 
  приятный восходящий аккорд. Должен быть заметным и вызывать радость!

### ⬆️ Новая эра

- **Поиск:** `level up fanfare`, `epic achievement`, `upgrade complete`, 
  `power up epic`
- **Какой должен быть:** Эпичный звук перехода на новый уровень.

### 🌟 Золотой объект (появление)

## 🎵 Фоновая музыка

### Главное меню
- **Файл:** `assets/music/menu_theme.ogg`
- **Длительность:** 1–3 минуты (будет зацикливаться)
- **Поиск:** `ambient background music`, `menu theme`, 
  `corporate ambient`, `tech ambient`
- **Где искать помимо Freesound:**
  - https://incompetech.com/ (Kevin MacLeod, CC BY)
  - https://www.bensound.com/ (некоторые треки бесплатны)
  - https://pixabay.com/music/ (бесплатная музыка)
- **Какой должен быть:** Спокойный, атмосферный, технологичный. 
  Не отвлекающий. Лёгкий эмбиент с электронными нотками.

### Игровой процесс
- **Файл:** `assets/music/game_theme.ogg`
- **Длительность:** 2–5 минут (будет зацикливаться)
- **Поиск:** `background game music`, `idle game music`, 
  `lo-fi beats`, `chill electronic`
- **Какой должен быть:** Чуть более энергичный чем меню, 
  но всё ещё ненавязчивый. Lo-fi, чилл электроника.

### Престиж
- **Файл:** `assets/music/prestige_theme.ogg` (опционально)
- **Длительность:** 30 секунд – 1 минута
- **Поиск:** `epic moment`, `transformation music`, `ascension theme`
- **Какой должен быть:** Короткий эпичный момент для анимации престижа.

## Советы по поиску на Freesound.org

1. **Залогинься** — без аккаунта нельзя скачивать
2. **Фильтруй по лицензии:**
   - В поиске нажми "Filter"
   - Выбери "Creative Commons 0" для максимальной свободы
   - Или "Attribution" если готов указать автора
3. **Сортируй по рейтингу** — лучшие звуки наверху
4. **Проверяй длительность** — не бери слишком длинные файлы
5. **Слушай перед скачиванием!** — не все звуки подходят по настроению
6. **Конвертируй если нужно:**
   - Если скачал .mp3 — конвертируй в .wav (для SFX)
   - Если скачал .wav музыку — конвертируй в .ogg (для экономии места)
   - Онлайн конвертер: https://cloudconvert.com/

## Лицензия

- **CC0 (Creative Commons Zero):** Полностью бесплатно, без ограничений
- **CC BY (Attribution):** Бесплатно, но нужно указать автора в credits
  Указывай авторов в файле `CREDITS.md` или в разделе "Авторы" в игре

## Если не хочешь искать вручную

Игра будет работать **без звуков**! Sound Manager корректно 
обрабатывает отсутствие файлов и просто не проигрывает звук. 
Так что можешь сначала запустить игру без звуков, а потом 
добавлять их постепенно.
